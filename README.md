# Provalen

Responsive, static landing page for Provalen. Built with HTML and CSS, with no
framework, build step, external fonts, or runtime dependencies. The titanium
and sapphire symbol is an SVG interpretation of the supplied Provalen identity.
The architectural scene is an original animated SVG, not stock imagery.
Animations and smooth scrolling respect reduced-motion preferences.

## Preview

Open `index.html` in a browser, or serve the repository root with a local static
web server.

## Publish

Deploy the repository root to any static web host. For GitHub Pages, select
**Settings > Pages > Deploy from a branch**, then choose **main** and **/(root)**.
The site becomes available after the files are committed and pushed.

Keep `index.html`, `styles.css`, `favicon.svg`, and `assets/` together. The contact
links open an email to `jeff@provalen.com`; no backend is required.
